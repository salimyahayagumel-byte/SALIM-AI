# SALIM AI TERMINAL V3.4 HUD + VOICE — Hausa/English + Voice Dashboard

## Render deployment
1. Upload this folder's files to a GitHub repository (keep `.env` and real API keys out of GitHub).
2. In Render choose **New + → Blueprint** and connect the repository containing `render.yaml`.
3. Set `GEMINI_API_KEY` to your private Google AI Studio key and set `DASHBOARD_PASSWORD` to a strong password. `FLASK_SECRET_KEY` is generated by Render.
4. Deploy. Open the service URL. `/health` should return `{"service":"SALIM AI dashboard","status":"ok"}`.

## HUD dashboard upgrade\nThe dashboard includes a responsive animated radar/HUD panel and live system status while keeping the existing chat, microphone, browser speech output, and password login.\n\nDefault Gemini model is `gemini-3.8-flash`; confirm your Google AI Studio API key has access to that model.\n\n## Voice dashboard
The dashboard uses browser Web Speech Recognition and Speech Synthesis. Use the HTTPS Render URL and allow microphone access. Speech recognition support and Hausa (`ha-NG`) availability depend on the browser/device; if Hausa recognition is unavailable, try English or type the message. Speech recognition happens in the browser; the Render server does not access the phone's microphone directly.

## Run on Termux
```sh
pkg install python
pip install -r requirements.txt
cp .env.example .env
# Edit .env and set GEMINI_API_KEY; do not share it publicly.
python bot.py
```
For the dashboard locally:
```sh
python webapp.py
```
Then open `http://127.0.0.1:5000`. Set `DASHBOARD_PASSWORD` in `.env` if you want login protection.

## Important limitation
Render cannot launch WhatsApp, TikTok, YouTube, or other native apps directly on a visitor's phone. It can return website links. Native app launching remains a local Termux/Android feature.
