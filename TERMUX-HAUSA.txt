SALIM AI V3.3 — UMARNIN HAUSA

1. Shigar da kayan aiki:
   pkg update
   pkg install python
   pip install -r requirements.txt

2. Shirya .env:
   cp .env.example .env
   nano .env
   Saka GEMINI_API_KEY naka a cikin .env. Kada ka tura wannan key zuwa GitHub ko ka aika wa kowa.

3. Fara AI a terminal:
   python bot.py

4. Fara dashboard:
   python webapp.py
   Sannan ka buɗe http://127.0.0.1:5000 a browser.

5. Don Render: duba README.md. Saka GEMINI_API_KEY da DASHBOARD_PASSWORD a Render Environment Variables.

Microphone na dashboard yana aiki ta browser idan browser ya goyi bayan Speech Recognition, an ba shi izinin microphone, kuma shafin yana HTTPS (Render URL). Hausa speech recognition na iya bambanta da browser; ana iya amfani da rubutu idan ba ya aiki.
